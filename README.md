## The entry

> The boy who stuttered read the morning announcements all the way through, and the whole schoolyard fell quiet in a way applause never could.

A quiet, earned moment of pride: a small person doing something hard — a boy who stutters reading the morning announcements all the way through — and a long effort finally landing, paid off by a whole schoolyard falling quiet.

## How it works

`main.ts` (pure Node.js standard library, no dependencies, no network) writes the single line to `/output/entry.txt`. The line is 1–240 characters of UTF-8 text, as the bounty requires.

```sh
node main.ts
cat /output/entry.txt
```
